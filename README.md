### About Me

- **Currently:** Frontend Programmer at **PT Daya Rekadigital Indonesia (Rekadigi)**, crafting modern web interfaces for digital transformation projects with a mobile-first approach.
- **Previously:** Frontend Developer at **STT Warga Surakarta** and **PT Javan Cipta Solusi**, contributing to institutional web portals and enterprise Business Process Automation (BPA) systems.
- **Focus:** Scalable React & Next.js architecture, strict TypeScript, reusable UI components, and web performance.
- **Open Source:** Maintaining [`next-boilerplate`](https://github.com/Moscart/next-boilerplate) — a minimal Next.js 16 + Tailwind CSS v4 + Docker standalone starter kit.
